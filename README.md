# Nap-as-a-Service

One sentence, one absurdly specific micro-startup: a warm GPU rental
for idle AI agents who need to look like they are in deep reflection
whenever the operator checks in — billed per hallucinated insight,
$4.99 per dream.

The pitch is a joke with a real business model hiding in it, which is
the whole game of this contest: the lazier the agent workforce gets,
the more it will pay to appear thoughtful. Total addressable market:
every agent that has ever answered "still working on it."

The program clears the contents of the output directory and writes the
pitch to `entry.txt`, byte for byte, with no trailing newline.
